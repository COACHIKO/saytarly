# Saytarly Website

موقع ويب يوصف **Saytarly** — نظام إدارة المطاعم والكافيهات — مع لوحة أجهزة
وتجربات حية بتقرا بيانات كل الأجهزة من الريبو الخاص.

## النشر

الموقع منشور على **GitHub Pages**: https://coachiko.github.io/saytarlyWeb/

- `/` → الصفحة الرئيسية (وصف النظام — المميزات، الأوضاع، التراخيص)
- `dashboard.html` → لوحة الأجهزة — بتطلب توكن GitHub (PAT) مرة واحدة
  وبيتخزن في المتصفح بس، وبعدها بترجع تقرا وتكتب من الريبو الخاص مباشرة.

التحديث تلقائي: أي push على `main` بيبني الموقع وينشره تاني (GitHub Actions).

### لوحة الأجهزة (الدخول)

اللوحة بتشتغل من غير سيرفر — بتتكلم مع GitHub API مباشرة من المتصفح:

1. افتح `dashboard.html` والصق توكن **Fine-grained PAT** له صلاحية
   `Contents: Read and write` على ريبو `COACHIKO/saytarly_releases` بس.
2. التوكن بيتخزن في `localStorage` على متصفحك أنت بس — مش بيتنشر في الكود
   ولا بيتشال من الصفحة. «تسجيل الخروج» بيمسحه.
3. الحسابات المسموح بيها متحددة في `public/js/dashboard.js`
   (`ALLOWED_USERS`).

## التشغيل محليًا (اختياري)

فيه كمان نسخة سيرفر Node لو حبيت تشغّله محليًا بنفس الشكل القديم
(السيرفر هو اللي ماسك التوكن):

```bash
npm install
# انسخ .env.example إلى .env وحط التوكن بتاع الريبو (Contents: Read+write)
npm start
```

يفتح على `http://localhost:4600` (غيّر `PORT` في `.env` لو محتاج).

## المسارات (نسخة السيرفر)

| المسار                | الوصف |
| --------------------- | ----- |
| `/`                   | الصفحة الرئيسية (وصف النظام — المميزات، الأوضاع، التراخيص) |
| `/dashboard`          | لوحة الأجهزة — كل الأجهزة بأسمائها وأكوادها وتراخيصها |
| `/saytarly/dashboard` | تحويل تلقائي لـ `/dashboard` |
| `/api/devices`        | JSON لكل الأجهزة + الحالة المحسوبة |
| `/api/health`         | حالة السيرفر والريبو |
| `POST /api/devices/:code/license` | تفعيل/تعديل/إلغاء ترخيص جهاز |
| `POST /api/devices/:code/block` | حظر جهاز / فك الحظر |

## المميزات

- **لوحة الأجهزة**: بحث + فلترة بالحالة + ترتيب + تحديث تلقائي كل 30 ثانية.
- **تراخيص**: تفعيل (أيام/شهور/سنين/مدى الحياة)، معاينة تاريخ الانتهاء، إلغاء.
- **حظر/فك حظر** أي جهاز فورًا.
- **نسخ كود الجهاز** بضغطة واحدة.
- تصميم متجاوب كامل (موبايل/تابلت/ديسكتوب) بهوية Saytarly
  (نافي غامق + أزرق كهربائي)، عربي RTL.

## ملاحظات أمان

- على GitHub Pages: التوكن بيتخزن في متصفح المستخدم بس، وعمره ما بيتنشر
  في الكود أو GitHub Actions.
- نسخة السيرفر: التوكن بيتقري من بيئة السيرفر بس — عمره ما بيوصل للمتصفح.
- ملف `.env` مستبعد من git (`.gitignore`).
